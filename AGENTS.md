## Reglas clave
1. 🗂️ **Organización**: crea archivos **solo** dentro de
   `C:/proyectos/Trading-Ciencia/` (o su subcarpeta); nada suelto fuera del proyecto.
2. 🔍 **Revisión**: en cada sesión audita el repo (`git status`, `README`, enlaces,
   badges) y repara errores simples de formato.
3. 🎨 **Documentación**: guías didácticas y visualmente agradables (badges, tablas,
   callouts, checklists y rutas de aprendizaje).
4. 🔒 **Cero secretos**: nunca claves, tokens ni API keys; usa `.env` + `.env.example`.
5. 🧪 **Honestidad científica**: no inventes resultados; el framework es educativo e
   investigativo y lleva aviso de riesgo (ver el Disclaimer del `README.md`).
